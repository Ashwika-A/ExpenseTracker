**Expense Tracker**

A simple console-based expense tracker built in Java. It lets you record daily expenses by category and date, view them, and see a spending summary. Your data is saved to a CSV file, so nothing is lost when the program closes.

Features
Add an expense with an amount, category, and date (press Enter to use today's date)
View all recorded expenses
See the total spending and a category-wise breakdown
See which category you spend the most on
Data is saved automatically to expenses.csv and loaded again on the next run
Input validation for invalid amounts, empty categories, and wrong date formats
